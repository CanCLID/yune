## Phase 1 Gap Summary

1. `schema_install.rs::load_schema_dictionary_by_name` currently treats rejected compiled table/prism/reverse data as `SourceFallback` when source YAML exists. M56 requires stale/corrupt compiled artifacts to be loud, so the fallback policy must distinguish missing compiled data from invalid/stale compiled data.
2. Cold/warm conformance is not a standing test for both named product paths from fresh dirs. Existing tests cover smaller fixtures and browser/runtime paths, but not the exact M56 deploy-select-type flow for committed `luna_pinyin` and TypeDuck `jyut6ping3`.
3. Poet and octagram are outside the default named product cold/warm path. They need artifact-specific stale/corrupt injection, not product-path cold-start claims.
4. Userdb has text headers but no explicit format-version row. Phase 2 must freeze the current format or name migration support.
