# M59 Lane B — Upstream Luna general single-character reachability (landed)

Delivers the owner requirement for `luna_pinyin`: pick single characters one at a
time to compose an **arbitrary** phrase (`moboyi`→`莫伯洢`, and any input — not a
named list). Reachability by paging, no promotion, no baked data, no per-input
gating.

## Mechanism (real, general, perf-conscious)

A narrow typed capability `translator/leading_syllable_reachability` (distinct
from the broad TypeDuck `prefix_fallback`), enabled in
`apps/yune-web/public/schema/luna_pinyin.schema.yaml`:

- **Complete/page-turn path:** injects the full leading-syllable single-character
  family (from the dictionary, via `leading_single_syllable_prefix_candidates`)
  after the phrase candidates, so any single is reachable by paging and selecting
  recomposes the remainder (M28).
- **Bounded typing path:** appends only a capped slice (`fetch_limit`) after the
  phrases and signals more-exists — no full-family materialization per keystroke.
- **Perf:** does NOT widen `ordered_mode` (luna keeps its bounded early-stop);
  ordering is preserved locally by the sentence-splice quality assignment. The
  untoned-code relaxation (luna `mo` has no tone digit) is gated to this lane so
  it does not broaden toned prefix-fallback schemas (jyutping).

## Acceptance (focused, non-circular, real byte-backed product path)

`crates/yune-rime-api/tests/yune_web.rs`, staged from **tracked**
`apps/yune-web/public/schema` (no dependency on the git-ignored `public-demo/dist`):

- `m59_luna_moboyi_composes_mo_bo_yi_on_byte_backed_product` — `moboyi` → page to
  莫 → select → recompose `boyi` → 伯 → `yi` → 洢 → commit **莫伯洢** (accumulated
  final-string asserted); storage asserted byte-backed (Compact, not owned-heap).
- `m59_luna_moboli_control_composes_mo_bo_li_on_byte_backed_product` — **control**
  in no allowlist / no baked data → **莫伯李** (proves generalization, not memory).
- `m59_luna_moboyi_keeps_phrases_on_first_page_without_promoting_singles` —
  phrase-before-single ordering; 莫 not promoted onto page 1; `is_last_page:false`.
